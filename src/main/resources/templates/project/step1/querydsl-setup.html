QueryDSL 설정

IntelliJ IDEA 기반 설정 가이드

1. 구현 내용 2. QueryDSL 설정 3. QueryDSL 이론

📦 1단계: build.gradle 의존성 추가

QueryDSL을 사용하기 위해 필요한 의존성을 build.gradle 파일에 추가합니다.

dependencies {
    // ... 기존 의존성들 ...

    // QueryDSL
    implementation 'com.querydsl:querydsl-jpa:5.0.0:jakarta'
    annotationProcessor 'com.querydsl:querydsl-apt:5.0.0:jakarta'
    annotationProcessor 'jakarta.annotation:jakarta.annotation-api'
    annotationProcessor 'jakarta.persistence:jakarta.persistence-api'
}

💡 주의사항: Spring Boot 3.x는 jakarta 네임스페이스를 사용하므로 :jakarta classifier를 반드시 추가해야 합니다.

⚙️ 2단계: Q클래스 생성 경로 설정

Annotation Processor가 생성하는 Q클래스의 저장 경로를 설정합니다.

// QueryDSL 설정
def querydslDir = "build/generated/querydsl"

sourceSets {
    main {
        java {
            srcDirs = ['src/main/java', querydslDir]
        }
    }
}

tasks.withType(JavaCompile).configureEach {
    options.annotationProcessorGeneratedSourcesDirectory = file(querydslDir)
}

clean {
    delete file(querydslDir)
}

✅ 생성 경로: build/generated/querydsl

🗑️ Clean 시: Q클래스 자동 삭제 후 재생성

🔧 3단계: JPAQueryFactory 빈 등록

JpaConfig.java에 QueryDSL을 사용하기 위한 JPAQueryFactory 빈을 등록합니다.

import com.querydsl.jpa.impl.JPAQueryFactory;
import jakarta.persistence.EntityManager;
import jakarta.persistence.PersistenceContext;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;

@Configuration
@EnableJpaAuditing
public class JpaConfig {

    @PersistenceContext
    private EntityManager entityManager;

    /**
     * QueryDSL JPAQueryFactory 빈 등록
     */
    @Bean
    public JPAQueryFactory jpaQueryFactory() {
        return new JPAQueryFactory(entityManager);
    }

    // ... 기타 설정들 ...
}

⚠️ 중요: EntityManager를 주입받아 JPAQueryFactory를 생성합니다. 이 빈은 QueryDSL Repository에서 @RequiredArgsConstructor로 자동 주입됩니다.

🚀 4단계: IntelliJ에서 Q클래스 생성

방법 1: Gradle 탭 사용 (권장)

  1. 1. IntelliJ 우측의 Gradle 탭 열기
  2. 2. 새로고침 버튼 클릭 (gradle 아이콘)
  3. 3. Tasks → build → clean 더블클릭
  4. 4. Tasks → build → build 더블클릭
  5. 5. build/generated/querydsl 폴더에 Q클래스 생성 확인

방법 2: 실행 버튼 사용

  1. 1. IntelliJ 우측 상단의 ▶ Run 버튼 클릭
  2. 2. 애플리케이션 실행 시 자동으로 Q클래스 생성됨

방법 3: Terminal 사용

./gradlew clean build

Windows: gradlew.bat clean build

📁 5단계: Generated Sources Root 설정

IntelliJ가 Q클래스를 인식하도록 생성된 폴더를 소스 폴더로 지정합니다.

방법 1: Project Structure 사용

  1. 1. File → Project Structure (또는 Ctrl+Alt+Shift+S)
  2. 2. Modules 클릭
  3. 3. Sources 탭 선택
  4. 4. build/generated/querydsl 폴더 찾기
  5. 5. 해당 폴더를 Generated Sources Root (파란색 폴더)로 설정
  6. 6. Apply → OK

방법 2: 우클릭 사용 (간편)

  1. 1. 프로젝트 탐색기에서 build/generated/querydsl 폴더 우클릭
  2. 2. Mark Directory as → Generated Sources Root 선택

💡 확인 방법: 설정이 완료되면 build/generated/querydsl 폴더가 파란색으로 표시되며, Q클래스를 import할 수 있습니다.

✅ 6단계: 사용 예시

QueryDSL Repository를 생성하고 Q클래스를 사용합니다.

import com.querydsl.jpa.impl.JPAQueryFactory;
import lombok.RequiredArgsConstructor;
import org.springframework.stereotype.Repository;

import static io.goorm.jpa.entity.QEnrollment.enrollment;
import static io.goorm.jpa.entity.QUser.user;
import static io.goorm.jpa.entity.QCourse.course;

@Repository
@RequiredArgsConstructor
public class EnrollmentQueryRepository {

    private final JPAQueryFactory queryFactory;

    public Page search(Long studentNo, Long courseNo) {
        List content = queryFactory
                .selectFrom(enrollment)
                .join(enrollment.student, user).fetchJoin()
                .join(enrollment.course, course).fetchJoin()
                .where(
                        enrollment.deleted.eq(false),
                        studentNoEq(studentNo),
                        courseNoEq(courseNo)
                )
                .fetch();

        return new PageImpl<>(content, pageable, total);
    }
}

✅ 성공: Q클래스(QEnrollment, QUser, QCourse)를 정상적으로 import하고 사용할 수 있습니다!

🔧 문제 해결

❌ Q클래스를 찾을 수 없어요

해결:

  • 1. Gradle 새로고침 후 clean + build 다시 실행
  • 2. build/generated/querydsl 폴더가 존재하는지 확인
  • 3. Generated Sources Root 설정 확인

⚠️ 빌드 오류가 발생해요

해결:

  • 1. QueryDSL 버전 확인 (5.0.0:jakarta)
  • 2. Spring Boot 3.x는 반드시 :jakarta classifier 필요
  • 3. Gradle 캐시 삭제: ./gradlew clean --refresh-dependencies

💡 IntelliJ가 Q클래스를 인식 못해요

해결:

  • 1. File → Invalidate Caches 실행
  • 2. IntelliJ 재시작
  • 3. Generated Sources Root 재설정
