🎯 QueryDSL이란?

QueryDSL은 타입 안전한 방식으로 동적 쿼리를 작성할 수 있게 해주는 프레임워크입니다. 문자열 기반 JPQL과 달리 컴파일 시점에 오류를 발견할 수 있습니다.

✅ 장점

  • • 컴파일 시점 타입 체크
  • • IDE 자동완성 지원
  • • 동적 쿼리 작성 용이
  • • 재사용 가능한 코드

📌 핵심 개념

  • • Q클래스 (QEntity)
  • • JPAQueryFactory
  • • BooleanExpression
  • • Fetch Join

🎓 사용 사례

  • • 검색 조건이 복잡한 경우
  • • 동적 필터링
  • • 페이징 + 정렬
  • • 집계 쿼리

📝 기본 문법

1. 기본 조회 (SELECT)

// JPQL
String jpql = "SELECT e FROM Enrollment e WHERE e.deleted = false";

// QueryDSL
List result = queryFactory
    .selectFrom(enrollment)
    .where(enrollment.deleted.eq(false))
    .fetch();

💡 Tip: selectFrom()은 SELECT와 FROM을 동시에 처리합니다.

2. 조건 검색 (WHERE)

// 단일 조건
List result = queryFactory
    .selectFrom(enrollment)
    .where(enrollment.status.eq(EnrollmentStatus.APPROVED))
    .fetch();

// 복수 조건 (AND)
List result = queryFactory
    .selectFrom(enrollment)
    .where(
        enrollment.status.eq(EnrollmentStatus.APPROVED),
        enrollment.deleted.eq(false)
    )
    .fetch();

// OR 조건
List result = queryFactory
    .selectFrom(enrollment)
    .where(
        enrollment.status.eq(EnrollmentStatus.APPROVED)
            .or(enrollment.status.eq(EnrollmentStatus.PENDING))
    )
    .fetch();

3. 비교 연산자

연산 QueryDSL 설명
= .eq(value) 같음
!= .ne(value) 같지 않음
> .gt(value) 초과
>= .goe(value) 이상
< .lt(value) 미만
<= .loe(value) 이하
LIKE .like("%value%") 포함
IN .in(values) 포함 여부
IS NULL .isNull() null 체크

🔗 JOIN

1. 기본 JOIN

// Inner Join
List result = queryFactory
    .selectFrom(enrollment)
    .join(enrollment.student, user)
    .join(enrollment.course, course)
    .where(enrollment.deleted.eq(false))
    .fetch();

2. Fetch JOIN (N+1 문제 해결)

// Fetch Join으로 한 번에 가져오기
List result = queryFactory
    .selectFrom(enrollment)
    .join(enrollment.student, user).fetchJoin()
    .join(enrollment.course, course).fetchJoin()
    .where(enrollment.deleted.eq(false))
    .fetch();

✅ N+1 해결: fetchJoin()을 사용하면 연관된 엔티티를 한 번의 쿼리로 가져와 N+1 문제를 방지합니다.

3. LEFT JOIN

// Left Outer Join
List result = queryFactory
    .selectFrom(course)
    .leftJoin(course.instructor, user).fetchJoin()
    .where(course.deleted.eq(false))
    .fetch();

📄 페이징 & 정렬

// offset, limit, orderBy
List content = queryFactory
    .selectFrom(enrollment)
    .where(enrollment.deleted.eq(false))
    .offset(pageable.getOffset())      // 시작 위치
    .limit(pageable.getPageSize())     // 가져올 개수
    .orderBy(enrollment.createdAt.desc())  // 정렬
    .fetch();

// 전체 개수 조회 (페이징에 필요)
Long total = queryFactory
    .select(enrollment.count())
    .from(enrollment)
    .where(enrollment.deleted.eq(false))
    .fetchOne();

// PageImpl 생성
return new PageImpl<>(content, pageable, total != null ? total : 0);

💡 Tip: 페이징 쿼리는 데이터 조회와 전체 개수 조회 두 번 실행됩니다.

🎨 동적 쿼리

사용자가 입력한 검색 조건에 따라 쿼리가 동적으로 변경되어야 할 때 사용합니다.

❌ 잘못된 방법: 문자열 조합

// 위험! SQL Injection 가능성
String jpql = "SELECT e FROM Enrollment e WHERE 1=1";
if (studentNo != null) {
    jpql += " AND e.student.userNo = " + studentNo;
}
if (status != null) {
    jpql += " AND e.status = '" + status + "'";
}

⚠️ 위험: SQL Injection 취약점, 타입 안정성 없음

✅ QueryDSL 방법: where() null 무시

// QueryDSL은 where()에 null이 들어오면 자동으로 무시
List result = queryFactory
    .selectFrom(enrollment)
    .where(
        studentNoEq(studentNo),    // null이면 무시
        courseNoEq(courseNo),      // null이면 무시
        statusEq(status)           // null이면 무시
    )
    .fetch();

// 조건 메서드들
private BooleanExpression studentNoEq(Long studentNo) {
    return studentNo != null ? enrollment.student.userNo.eq(studentNo) : null;
}

private BooleanExpression courseNoEq(Long courseNo) {
    return courseNo != null ? enrollment.course.courseNo.eq(courseNo) : null;
}

private BooleanExpression statusEq(EnrollmentStatus status) {
    return status != null ? enrollment.status.eq(status) : null;
}

✅ 안전: 타입 안전, 컴파일 체크, null 자동 처리

📊 집계 함수

// COUNT
Long count = queryFactory
    .select(enrollment.count())
    .from(enrollment)
    .where(enrollment.status.eq(EnrollmentStatus.APPROVED))
    .fetchOne();

// SUM
Integer total = queryFactory
    .select(course.currentStudents.sum())
    .from(course)
    .where(course.deleted.eq(false))
    .fetchOne();

// AVG
Double average = queryFactory
    .select(course.currentStudents.avg())
    .from(course)
    .fetchOne();

// MIN, MAX
Integer min = queryFactory.select(course.currentStudents.min()).from(course).fetchOne();
Integer max = queryFactory.select(course.currentStudents.max()).from(course).fetchOne();

🎯 조건 분리 패턴 (BooleanExpression)

복잡한 조건을 재사용 가능한 메서드로 분리하여 코드 가독성과 유지보수성을 높이는 방법을 학습합니다.

BooleanExpression isAvailable() { return course.currentStudents.lt(course.maxStudents) .and(course.deleted.eq(false)); }
