✅ 완료된 API 엔드포인트

🔐 인증 (Auth)

Method Endpoint 기능
POST /api/auth/login 로그인 (JWT 발급)

📝 게시판 (Board) - Query Methods

Method Endpoint 기능
GET /api/boards 게시글 목록 조회 (페이징, 검색)
GET /api/boards/{boardNo} 게시글 상세 조회 (조회수 증가)
POST /api/boards 게시글 작성
PUT /api/boards/{boardNo} 게시글 수정 (본인 확인)
DELETE /api/boards/{boardNo} 게시글 삭제 (Soft Delete)
GET /api/boards/my 내가 쓴 글 목록

📚 강의 (Course) - JPQL + Fetch Join

Method Endpoint 기능
GET /api/courses 강의 목록 조회 (페이징, 검색, 수강 가능)
GET /api/courses/{courseNo} 강의 상세 조회
POST /api/courses 강의 생성 (강사/관리자)
PUT /api/courses/{courseNo} 강의 수정 (담당 강사/관리자)
GET /api/courses/my 내 강의 목록 (강사용)

✏️ 수강신청 (Enrollment) - QueryDSL + Optimistic Lock

Method Endpoint 기능
POST /api/enrollments 수강신청 (Optimistic Lock, 재시도 로직)
GET /api/enrollments/my 내 수강신청 목록
GET /api/enrollments 수강신청 관리 (동적 검색: studentNo, courseNo, status)
PUT /api/enrollments/{enrollmentNo}/approve 수강신청 승인 (관리자)
PUT /api/enrollments/{enrollmentNo}/reject 수강신청 거절 (관리자)
PUT /api/enrollments/{enrollmentNo}/cancel 수강신청 취소 (학생 본인)

👤 사용자 프로필 (UserProfile) - OneToOne 단방향

Method Endpoint 기능
GET /api/profile 내 프로필 조회
POST /api/profile 프로필 생성
PUT /api/profile 프로필 수정

🎯 Step 1 학습 내용

연관관계 매핑

  • ✓ ManyToOne 단방향: Board, Course, Enrollment → User
  • ✓ OneToOne 단방향: UserProfile → User
  • ✓ Lazy Loading: 모든 연관관계에 FetchType.LAZY 적용

쿼리 작성 기술

  • ✓ Query Methods: Board 간단한 조건 검색
  • ✓ JPQL + Fetch Join: Course N+1 문제 해결
  • ✓ QueryDSL: Enrollment 동적 쿼리

동시성 제어

  • ✓ Optimistic Lock: Enrollment @Version
  • ✓ 재시도 로직: 최대 3회 재시도
  • ✓ 동시성 테스트: 수강신청 경합 상황 처리

기타 주요 기술

  • ✓ Soft Delete: BaseEntity.deleted 패턴
  • ✓ JPA Auditing: 생성자/수정자 자동 기록
  • ✓ DTO Pattern: Java Record 활용
