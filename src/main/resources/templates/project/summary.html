프로젝트 설계

학사관리 시스템 - 기술 스택 및 ERD

🔧 사용 기술 스택

⚙️ Backend

  • Java 21
  • Spring Boot 3.5.6
  • Spring Data JPA (Hibernate 6)
  • Spring Security
  • QueryDSL 5.0.0

🗄️ Database

  • H2 Database (in-memory)
  • P6Spy (SQL 로깅)
  • JPA Auditing

🔐 Security

  • Session-based Authentication
  • BCrypt Password Encoder
  • Spring Security Session

🎨 Frontend

  • Thymeleaf (템플릿 엔진)
  • DaisyUI + Tailwind CSS
  • Fetch API (비동기 통신)

🛠️ Tools

  • Lombok
  • Validation (Jakarta Bean Validation)
  • Swagger/OpenAPI 3
  • Spring Boot Actuator

🔍 Query Technologies

  • Query Methods (Board)
  • JPQL + Fetch Join (Course)
  • QueryDSL (Enrollment)

📐 ERD (Entity Relationship Diagram)

💡 핵심 엔티티 (Step 1)

  • • User: 사용자 (ADMIN, INSTRUCTOR, STUDENT)
  • • Board: 게시판 (User와 ManyToOne 단방향)
  • • Course: 강의 (User(instructor)와 ManyToOne 단방향)
  • • Enrollment: 수강신청 (User, Course와 ManyToOne 단방향)
  • • UserProfile: 사용자 프로필 (User와 OneToOne 단방향)
