✨ 신규 엔드포인트

Step 2에서 양방향 관계를 통해 새롭게 추가된 엔드포인트입니다.

💬 게시판 댓글 (Board ↔ Comment 양방향)

Method Endpoint 기능 적용 기술
GET /api/boards/{boardNo}/comments 댓글 목록 조회 @OneToMany
POST /api/boards/{boardNo}/comments 댓글 작성 편의 메소드
PUT /api/boards/{boardNo}/comments/{commentNo} 댓글 수정 기본 CRUD
DELETE /api/boards/{boardNo}/comments/{commentNo} 댓글 삭제 Soft Delete

📚 강의 커리큘럼 (Course ↔ Week ↔ Session 양방향)

Method Endpoint 기능 적용 기술
GET /api/courses/{courseNo}/curriculum 커리큘럼 조회 (주차 → 차시) @OneToMany 계층
POST /api/courses/{courseNo}/weeks 주차 추가 편의 메소드
POST /api/weeks/{weekNo}/sessions 차시 추가 편의 메소드

👥 수강생 목록 (Course ↔ Enrollment 양방향)

Method Endpoint 기능 적용 기술
GET /api/courses/{courseNo}/students 수강생 목록 조회 (승인된 학생) @OneToMany

🎯 주요 변경 사항

1. 양방향 관계 추가

  • • Board ↔ Comment: @OneToMany 양방향
  • • Course ↔ Week: @OneToMany 양방향
  • • Week ↔ Session: @OneToMany 양방향
  • • Course ↔ Enrollment: @OneToMany 양방향

2. 편의 메소드

  • • board.addComment(comment)
  • • course.addWeek(week)
  • • week.addSession(session)
  • • 양쪽 참조를 자동으로 설정하여 일관성 유지

3. Cascade 적용

  • • CascadeType.PERSIST: 부모 저장 시 자식도 저장
  • • CascadeType.REMOVE: 부모 삭제 시 자식도 삭제
  • • Course 삭제 시 Week, Session 자동 삭제
  • • Board 삭제 시 Comment 자동 삭제

4. 고아 객체 제거

  • • orphanRemoval = true
  • • 컬렉션에서 제거된 엔티티 자동 삭제
  • • 예: course.getWeeks().remove(week) → DB에서 삭제
