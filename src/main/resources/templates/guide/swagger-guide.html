💡 Tip: Swagger UI는 자동으로 Controller의 모든 엔드포인트를 문서화합니다.

🏷️ 주요 Swagger 어노테이션

@Tag

Controller 그룹화

Controller를 논리적 그룹으로 묶어 표시합니다.

@Tag(name = "인증", description = "로그인/로그아웃 API")
@RestController
@RequestMapping("/api/auth")
public class AuthController {
    // ...
}
@Operation

API 설명 추가

각 API 메서드에 대한 상세 설명을 추가합니다.

@Operation(
    summary = "사용자 로그인",
    description = "username과 password로 로그인하고 JWT 토큰을 발급받습니다."
)
@PostMapping("/login")
public ResponseEntity<ApiResponse<LoginResponse>> login(...) {
    // ...
}
@Parameter

파라미터 설명

PathVariable, RequestParam 등의 설명을 추가합니다.

@GetMapping("/{id}")
public ResponseEntity<User> getUser(
    @Parameter(description = "사용자 ID", example = "1")
    @PathVariable Long id
) {
    // ...
}
@Schema

DTO 필드 설명

Request/Response DTO의 각 필드를 설명합니다.

public record LoginRequest(
    @Schema(description = "사용자 아이디", example = "admin")
    String username,

    @Schema(description = "비밀번호", example = "1234")
    String password
) {}
@ApiResponse

응답 코드 설명

가능한 HTTP 응답 코드와 설명을 추가합니다.

@Operation(summary = "사용자 로그인")
@ApiResponses({
    @ApiResponse(responseCode = "200", description = "로그인 성공"),
    @ApiResponse(responseCode = "401", description = "인증 실패"),
    @ApiResponse(responseCode = "404", description = "사용자를 찾을 수 없음")
})
@PostMapping("/login")
public ResponseEntity<LoginResponse> login(...) {
    // ...
}

📝 어노테이션 우선순위

  1. 필수: @Tag (Controller 그룹화)
  2. 권장: @Operation (API 설명)
  3. 선택: @Schema, @Parameter (상세 문서화)

📤 Postman으로 내보내기

Swagger UI에서 생성된 OpenAPI 스펙을 Postman으로 가져와서 바로 테스트할 수 있습니다.

1️⃣ OpenAPI JSON 다운로드

Swagger가 제공하는 OpenAPI 스펙 파일을 다운로드합니다.

OpenAPI JSON 다운로드 →

브라우저에서 열리면 우클릭 → "다른 이름으로 저장" 또는 Ctrl+S로 저장하세요.

2️⃣ Postman에서 Import

  1. Postman 실행
  2. 좌측 상단 Import 버튼 클릭
  3. Upload Files 탭에서 다운로드한 JSON 파일 선택
  4. 또는 Link 탭에서 URL 입력: 
    http://localhost:8080/v3/api-docs
  5. Import 버튼 클릭

3️⃣ Collection 생성 확인

Postman에 "JPA 학습 프로젝트 API" Collection이 생성됩니다.

  • 모든 API 엔드포인트가 자동으로 추가됨
  • Request Body 예시가 자동으로 포함됨
  • 각 API의 설명도 함께 import됨

4️⃣ 환경 변수 설정 (선택)

baseUrl을 환경 변수로 설정하면 편리합니다.

  1. Postman 우측 상단 ⚙️ (Manage Environments) 클릭
  2. Add 버튼으로 새 환경 생성 (예: "Local")
  3. 변수 추가: 
    Variable: baseUrl
Value: http://localhost:8080
  4. URL에서 {{baseUrl}}/api/auth/login 형식으로 사용

💡 실무 팁

  • • 개발 중에는 Swagger UI로 빠르게 테스트
  • • 복잡한 시나리오는 Postman Collection으로 저장
  • • Postman의 Pre-request Script로 자동 로그인 처리 가능
  • • Collection을 팀원들과 공유하면 협업에 유용

🔐 Swagger UI에서 JWT 인증

1. 로그인 API 호출

POST /api/auth/login으로 토큰 발급받기 

{
  "username": "admin",
  "password": "1234"
}

Response: 

{
  "token": "eyJhbGciOiJIUzI1NiJ9...",
  "userId": 1,
  "username": "admin",
  "role": "ADMIN"
}

2. Authorize 버튼 클릭

Swagger UI 우측 상단의 🔓 Authorize 버튼 클릭

3. 토큰 입력

받은 토큰을 입력창에 붙여넣기 (Bearer는 자동으로 추가됨)

Value:

eyJhbGciOiJIUzI1NiJ9...

⚠️ "Bearer "를 직접 입력하지 마세요! 토큰 값만 입력하면 됩니다.

4. Authorize 버튼 클릭

팝업창 하단의 Authorize 버튼을 클릭하면 설정 완료!

✅ 이제 모든 API 요청에 자동으로 Authorization: Bearer {token} 헤더가 추가됩니다.

🔄 토큰 만료 시

토큰이 만료되면 (24시간 후) 401 Unauthorized 응답을 받게 됩니다. 다시 로그인하여 새 토큰을 발급받고 Authorize 과정을 반복하세요.
