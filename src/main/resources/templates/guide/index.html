JPA 학습 프로젝트

Spring Boot + JPA 기반 REST API 학습 프로젝트

Milestone 0: Backbone

🔧 적용된 기술 스택

⚙️ Backend

  • Java 21
  • Spring Boot 3.5.6
  • Spring Data JPA
  • Spring Security
  • Hibernate 6

🗄️ Database

  • H2 Database (in-memory)
  • P6Spy (SQL 로깅)
  • JPA Auditing

🔐 Security

  • JWT (jjwt 0.12.3)
  • BCrypt Password Encoder
  • Stateless Session

🎨 Frontend

  • Thymeleaf (템플릿 엔진)
  • Tailwind CSS (via CDN)
  • Thymeleaf Layout Dialect

🛠️ Tools

  • Lombok
  • Validation
  • Swagger/OpenAPI 3 (springdoc 2.8.4)
  • Spring Boot Actuator

⚠️ Exception Handling

  • ErrorCode Enum
  • RestApiExceptionHandler
  • MvcExceptionHandler
  • MessageSource (i18n)

💡 주요 설계 포인트

✅ 계층별 패키지 구조 (Layer-First)

controller, service, repository 계층 우선 분리

✅ API vs MVC 분리

controller.api (@RestController) / controller.web (@Controller)

✅ PK 네이밍 규칙

userNo, boardNo 등 명확한 이름 사용 (id 사용 지양)

✅ BaseEntity 상속

Auditing 및 Soft Delete 자동 지원

🚨 에러 페이지

웹 페이지에서 발생하는 에러는 커스텀 에러 페이지로 처리됩니다.

📄 404 Not Found

존재하지 않는 페이지 접근 시

templates/error/404.html

⚠️ 기타 에러

500, 403 등 기타 에러

templates/error/error.html

API 에러: /api/** 경로는 RestApiExceptionHandler가 JSON으로 처리합니다.
