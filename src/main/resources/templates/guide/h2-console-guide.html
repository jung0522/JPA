⚙️ 정적 설정 파일 사용하기

매번 JDBC URL을 입력하는 대신, H2의 .h2.server.properties 파일로 저장할 수 있습니다.

방법 1: H2 Console에서 저장

  1. H2 Console 접속
  2. 로그인 화면에서 접속 정보 입력 
    JDBC URL: jdbc:h2:mem:testdb
User Name: sa
Password: (공백)
  3. 하단 "Save" 체크박스 클릭
  4. "Test Connection"으로 연결 테스트
  5. "Connect" 클릭

→ 다음부터는 저장된 설정이 자동으로 표시됩니다.

방법 2: 수동으로 파일 생성

사용자 홈 디렉토리에 .h2.server.properties 파일 생성:

Windows:

C:\Users\{사용자명}\.h2.server.properties

Mac/Linux:

~/.h2.server.properties 
0=Generic H2 (Embedded)|org.h2.Driver|jdbc\\:h2\\:mem\\:testdb|sa
webAllowOthers=false
webPort=8082

🔧 동시 접속 문제 해결

⚠️ 문제 상황

H2 인메모리 데이터베이스는 기본적으로 하나의 연결만 허용합니다.
애플리케이션이 실행 중일 때 H2 Console로 접속하면 오류가 발생할 수 있습니다.

✅ 해결방법: AUTO_SERVER=TRUE 추가

JDBC URL에 AUTO_SERVER=TRUE를 추가하면 여러 연결을 허용합니다.

기본 URL (단일 연결)

jdbc:h2:mem:testdb

수정된 URL (다중 연결 허용)

jdbc:h2:mem:testdb;AUTO_SERVER=TRUE

application-jpa.properties 수정 (선택)

프로젝트 전체에 적용하려면 설정 파일을 수정하세요: 

# 기존
spring.datasource.url=jdbc:h2:mem:testdb

# 수정 (다중 연결 허용)
spring.datasource.url=jdbc:h2:mem:testdb;AUTO_SERVER=TRUE

또는: H2 Console에서만 사용

H2 Console 로그인 화면에서 JDBC URL에 직접 입력:

jdbc:h2:mem:testdb;AUTO_SERVER=TRUE
sa
(공백)

💡 추가 옵션

MODE=MySQL MySQL 호환 모드로 실행
DB_CLOSE_DELAY=-1 마지막 연결이 끊겨도 DB 유지
TRACE_LEVEL_SYSTEM_OUT=2 디버그 로그 출력

여러 옵션은 세미콜론(;)으로 연결: jdbc:h2:mem:testdb;AUTO_SERVER=TRUE;MODE=MySQL

📝 자주 사용하는 SQL

테이블 목록 조회

SHOW TABLES;

테이블 구조 확인

SHOW COLUMNS FROM users;

전체 데이터 조회

SELECT * FROM users;

데이터 개수 확인

SELECT COUNT(*) FROM users;

⚠️ 주의: 인메모리 데이터베이스

  • • 애플리케이션 재시작 시 모든 데이터가 초기화됩니다.
  • • JpaDataInitializer가 자동으로 테스트 데이터를 생성합니다.
  • • 영구 저장이 필요하면 파일 기반 H2 또는 MySQL/PostgreSQL 사용
