편의 메서드란?

정의

편의 메서드(Convenience Method)는 복잡한 작업을 단순화하거나, 자주 사용되는 패턴을 메서드로 추상화하여 코드의 가독성과 재사용성을 높이는 메서드입니다.

핵심: 복잡한 로직을 숨기고, 사용하기 쉬운 인터페이스를 제공하는 것

일반적인 예시

// 복잡한 작업을 단순화
public class BankAccount {
    private double balance;
    private String accountNumber;
    
    // 편의 메서드: 복잡한 로직을 단순화
    public void transfer(BankAccount to, double amount) {
        if (this.balance >= amount) {
            this.withdraw(amount);
            to.deposit(amount);
        } else {
            throw new InsufficientFundsException();
        }
    }
    
    // 기본 메서드들
    public void withdraw(double amount) { /* ... */ }
    public void deposit(double amount) { /* ... */ }
}

사용 예시

// 편의 메서드 사용
BankAccount account1 = new BankAccount();
BankAccount account2 = new BankAccount();

// 복잡한 로직을 한 번의 메서드 호출로
account1.transfer(account2, 1000.0);

// 편의 메서드 없이 한다면?
if (account1.getBalance() >= 1000.0) {
    account1.withdraw(1000.0);
    account2.deposit(1000.0);
} else {
    throw new InsufficientFundsException();
}

왜 편의 메서드가 필요한가?

문제 상황

복잡한 객체 관계

// 두 객체 간의 관계 설정
public class Student {
    private List<Course> courses = new ArrayList<>();
}

public class Course {
    private List<Student> students = new ArrayList<>();
}

// 관계 설정 시 매번 해야 할 일
Student student = new Student();
Course course = new Course();

// 1. student의 courses에 course 추가
student.getCourses().add(course);

// 2. course의 students에 student 추가  
course.getStudents().add(student);

// 실수하기 쉬운 부분들:
// - 한쪽만 설정하는 경우
// - 순서를 바꾸는 경우
// - null 체크를 깜빡하는 경우

해결책

편의 메서드로 해결

// 편의 메서드 추가
public class Student {
    private List<Course> courses = new ArrayList<>();
    
    public void enrollIn(Course course) {
        if (course != null) {
            this.courses.add(course);
            course.getStudents().add(this);
        }
    }
}

public class Course {
    private List<Student> students = new ArrayList<>();
    
    public void addStudent(Student student) {
        if (student != null) {
            this.students.add(student);
            student.getCourses().add(this);
        }
    }
}

// 사용법 - 간단하고 안전
student.enrollIn(course);
// 또는
course.addStudent(student);

편의 메서드 기본 패턴

1. 관계 설정 패턴

// 양방향 관계 설정
public void addItem(Item item) {
    if (item != null) {
        this.items.add(item);
        item.setParent(this);
    }
}

public void removeItem(Item item) {
    if (item != null) {
        this.items.remove(item);
        item.setParent(null);
    }
}

2. 검증 포함 패턴

// 비즈니스 규칙 검증 포함
public void addStudent(Student student) {
    if (student == null) {
        throw new IllegalArgumentException("Student cannot be null");
    }
    
    if (this.students.size() >= this.maxStudents) {
        throw new IllegalStateException("Course is full");
    }
    
    this.students.add(student);
    student.getCourses().add(this);
}

3. 복합 작업 패턴

// 여러 단계를 하나의 메서드로
public void approveEnrollment(Enrollment enrollment) {
    // 1. 상태 변경
    enrollment.setStatus(EnrollmentStatus.APPROVED);
    
    // 2. 수강생 수 증가
    this.currentStudents++;
    
    // 3. 알림 발송
    notificationService.sendApprovalNotification(enrollment);
    
    // 4. 로그 기록
    auditService.logEnrollmentApproval(enrollment);
}

실제 예시

쇼핑몰 예시

public class ShoppingCart {
    private List<CartItem> items = new ArrayList<>();
    private Customer customer;
    
    // 편의 메서드: 상품 추가
    public void addProduct(Product product, int quantity) {
        if (product == null || quantity <= 0) {
            throw new IllegalArgumentException("Invalid product or quantity");
        }
        
        // 기존 상품이 있는지 확인
        Optional<CartItem> existingItem = items.stream()
                .filter(item -> item.getProduct().equals(product))
                .findFirst();
        
        if (existingItem.isPresent()) {
            existingItem.get().addQuantity(quantity);
        } else {
            CartItem newItem = new CartItem(product, quantity);
            items.add(newItem);
            newItem.setCart(this);
        }
    }
    
    // 편의 메서드: 상품 제거
    public void removeProduct(Product product) {
        items.removeIf(item -> item.getProduct().equals(product));
    }
    
    // 편의 메서드: 장바구니 비우기
    public void clear() {
        items.clear();
    }
}

// 간단하고 직관적
ShoppingCart cart = new ShoppingCart();

cart.removeProduct(product);
cart.clear();

편의 메서드 없이

// 복잡하고 실수하기 쉬움
ShoppingCart cart = new ShoppingCart();
Product product = new Product();

// 상품 추가 로직을 매번 작성
if (product != null && quantity > 0) {
    Optional<CartItem> existingItem = cart.getItems().stream()
            .filter(item -> item.getProduct().equals(product))
            .findFirst();
    
    if (existingItem.isPresent()) {
        existingItem.get().addQuantity(quantity);
    } else {
        CartItem newItem = new CartItem(product, quantity);
        cart.getItems().add(newItem);
        newItem.setCart(cart);
    }
}

편의 메서드의 장점

코드 품질 향상

  • • 가독성: 코드의 의도가 명확하게 드러남
  • • 재사용성: 동일한 로직을 여러 곳에서 사용
  • • 유지보수성: 로직 변경 시 한 곳만 수정
  • • 테스트 용이성: 개별 메서드 단위로 테스트 가능

개발자 경험

  • • 실수 방지: 복잡한 로직을 자동화
  • • 일관성: 동일한 패턴으로 처리
  • • 효율성: 반복 작업을 줄임
  • • 학습 용이성: 새로운 개발자도 쉽게 이해

언제 편의 메서드를 만들까?

  • • 반복되는 패턴: 같은 로직을 여러 번 작성할 때
  • • 복잡한 작업: 여러 단계가 필요한 작업
  • • 비즈니스 규칙: 도메인 로직이 포함된 작업
  • • 에러 처리: 검증이나 예외 처리가 필요한 작업
  • • 관계 설정: 객체 간의 관계를 설정하는 작업
